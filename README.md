# The Final Shift (TFS)

A 15-floor office platformer that runs in the browser. You play a night-shift IT tech who climbs Synergex Tower, beats two mini bosses and the CEO, and uploads the loophole that ends the shift for good.

## Play

Open `index.html` in Chrome, Safari, Edge or Firefox. Nothing to install.

## Controls

| Key | Action |
| --- | --- |
| ← → or A D | Move |
| Space / W / ↑ | Jump (hold for higher) |
| S / ↓ | Drop through desks |
| F | Throw IT gear |
| R | Restart the current floor |
| T | Show or hide the stopwatch |
| P / Esc | Pause |

Progress, best times and ghosts are saved in your browser.
